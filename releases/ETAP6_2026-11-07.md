# NOVACELL Etap 6 — historia wydania

Wydania: NOVACELL Manager **0.6.0**, NOVACELL Theme **0.5.0**, NOVACELL Visual Editor **0.2.0**.

Zmiany:
- Właściwy, czytelny punkt wejścia Visual Editor (główne menu WordPress, dashboard, skrót na pasku administracyjnym i w liście wtyczek).
- Tworzenie i wielokrotne otwieranie jednego prywatnego szkicu Gutenberg, bez publikowania demonstracyjnej strony na frontend.
- Bezpośrednie skróty do wszystkich podstron administracyjnych NovaCell Managera, naprawiające mylenie slugów panelu z adresami WWW.
- Stabilniejsze rozpoznawanie tras, blokada tras nieopublikowanych rekordów, diagnostyka HTTP i raport gotowości.
- Import bez nadpisywania ręcznych edycji i bez odbierania zatwierdzeń przy identycznym reimporcie.
- Bezpieczny publiczny podgląd zgodnie z życzeniem właściciela, ale bez fikcyjnych akceptacji klinicznych i bez indeksowania niezweryfikowanych materiałów.
- Wspólny edytor dwujęzyczny WYSIWYG, modernizacja menedżera strony głównej.
- Ikony SVG, screenshot motywu, podstawowe SEO, sitemap zatwierdzonych materiałów i mapa historycznych przekierowań.

Testy: testy izolowane PHP na danych z dokumentacji; sprawdzenie składni PHP i JS; kontrola archiwów ZIP i SHA256. **Brak zewnętrznego testu rzeczywistego hostingu, pełnego WCAG 2.2 AA i Lighthouse.**

Pakiety instalacyjne są odrębne, dokumentacja jest poza nimi. GitHub zawiera jedynie kod źródłowy publiczny, nie materiał źródłowy kliniki.
