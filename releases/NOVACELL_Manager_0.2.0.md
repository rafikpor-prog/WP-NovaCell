# Manager 0.2.0

Automatyczny, idempotentny importer 10 rekordów, 9 sekcji i 3 stron; zarządzanie pozycjami strony głównej (drag-and-drop + W górę/W dół), edytory WYSIWYG i zakładki Polski/Angielski, odrębne podstrony PL/EN. Importowane rekordy to szkice bez publikacji. Źródłowa treść medyczna nie jest w publicznym GitHub (osobny prywatny JSON wyłącznie w instalacyjnym ZIP). Instrukcja: docs/ETAP2_ZASADY.md. Testy: lokalny mock smoke, PHP lint; pełne testy WP i WCAG pozostają do wykonania.
