# Theme 0.1.0

Pierwszy motyw frontendowy NOVACELL: 9 sekcji z Managera, architektura PL/EN, 12 dwujęzycznych map tras, karty lekarzy/problemów, responsywny interfejs, logo SVG odwzorowane z dostarczonego PNG, 13 ikon SVG, Manrope+Inter, palette #9ED2DF #55A9CE #183B50 #F5FAFC. Publiczne ścieżki szablonów są blokowane do chwili akceptacji medycznej. Korzystanie: zainstalować Manager 0.2.0, potem Theme 0.1.0; edytować przez NOVACELL Manager. Testy lokalne bez pełnego WordPress; formalny audyt WCAG 2.2 AA jest planowany.
